Privacy Policy

Effective 7 November 2026

1. Local first

VelocePDF processes PDFs locally. The Flask preview holds documents in memory for the session and does not write them to disk. Files are discarded when the tab closes.

2. No tracking

We make no network requests while reading. We do not log document contents or passwords. Reading history (Frequently Read) is stored in localStorage only if you keep it enabled, and you can clear it at any time.

3. Passwords

Password-protected PDFs are decrypted in memory for the active tab. Passwords are never persisted or logged.

4. External links

Links in PDFs require confirmation and are limited to http, https, and mailto. No auto-fetch is performed.

5. Data you share

If you report an issue and attach a sample PDF, that file is handled per our security policy and not retained longer than needed for debugging.

6. Contact

Privacy questions: security@velocepdf.example
